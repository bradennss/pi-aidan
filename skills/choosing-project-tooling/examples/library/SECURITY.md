# Security

This is an unpublished reference package with no release support policy. Review it before adapting it for production. Do not submit secrets, private input, or working exploit payloads in public issues.

For a suspected vulnerability, use the hosting repository's private vulnerability reporting feature if enabled. Otherwise, ask a repository maintainer for a private reporting channel without disclosing vulnerability details publicly. This example does not promise a response or remediation deadline.

When reporting privately, include the affected revision, impact, and a minimal reproduction with non-sensitive input. Apply fixes to your own copy and rerun the parser and packed-consumer checks before relying on them.
